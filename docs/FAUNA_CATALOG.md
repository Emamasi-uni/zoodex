## 💾 Esportazione e API

- Il database completo in formato JSON pronto all'uso è disponibile su:
  - File locale: `backend/app/data/continental_fauna.json`
  - Endpoint HTTP: `GET http://<SERVER_IP>:8000/api/v1/catalog-export`
- I dati degli sblocchi del dispositivo Pixel 8a sono salvati in modo permanente su:
  - `backend/unlocked_dex.json`
